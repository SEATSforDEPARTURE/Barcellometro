# Embed rendering standard (single source of truth)

Il contratto ufficiale unico di rendering embed è definito in:

- `docs/embed_command_rendering_standard.md`

Regola normativa per tutto il repo:

- `description` = introduzione narrativa breve (corsivo);
- `fields` = sezioni importanti reali;
- no heading/sezioni importanti lasciate come testo libero in description, salvo eccezioni documentate.
